# Mayank Kamdi Portfolio and BIOS Hackathon

The root `/` is an accessible Mayank Kamdi portfolio hero based on the supplied parchment-and-celestial reference. Its opening frame remains faithful to the reference, then a reversible scroll-driven sequence moves the layered human/android artwork, background and gold focal point before revealing a copy-led continuation. The role line remains visible, and `prefers-reduced-motion` disables the pinned scroll journey. Illustration layers, fonts, logo mark, CSS and JavaScript are served from local project assets. The remaining route set preserves the public BIOS Hackathon pages, observed access gates and interactions; its declarations are in `public/manus-routes.json`.

Until separate portfolio page destinations or contact details are supplied, the visible portfolio navigation and calls to action point to existing local BIOS routes. No private account content or personal email address is fabricated.

## Development

Requires Node.js and pnpm (the exact pnpm version is pinned in `package.json`).

```bash
pnpm install --frozen-lockfile
pnpm dev
```

## Production build

```bash
pnpm build
```
